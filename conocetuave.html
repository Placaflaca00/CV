ConoceTuAve — a regional bird-call classifier

A two-stage audio classifier for 20 Paraguayan bird species — frozen BirdNET V2.4 embeddings into a fine-tuned head — taken all the way to production on AWS Lambda, with a public demo and a human-in-the-loop retraining pipeline.

Overview

  • Built a two-stage audio classifier (frozen BirdNET V2.4 1024-d embeddings → fine-tuned MLP head) for 20 Paraguayan bird species, reaching 94.6% / 81.3% top-1 accuracy on clean / hard out-of-distribution test sets (559 held-out clips, zero train/test overlap).
  • Beat a fair, label-space-matched BirdNET baseline by +8–10pp balanced accuracy across both folds — recovering rare regional species (Rhea, Pipile, Calidris canutus) that BirdNET can’t separate even when restricted to the same 20 classes.
  • Deployed to production as a containerised AWS Lambda (ECR + API Gateway HTTP API) serving ~128 ms inference / ~1.15 s end-to-end, with predictions bit-identical to local (zero containerisation drift).
  • Engineered the full data → model → serve lifecycle: automated audio QA, label-noise auditing cross-checked against BirdNET as an external oracle, ONNX export, CI/CD via GitHub Actions (OIDC), CloudWatch monitoring, and a public Gradio demo on HuggingFace Spaces.
  • Hardened reliability: cold-start mitigation (EventBridge pre-warming + client retry), 4-layer anti-abuse input validation, and a consent-gated DynamoDB → S3 feedback loop feeding a human-reviewed retraining pipeline.
