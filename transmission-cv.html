Drone-based component detection on power transmission lines

An 18-class instance-segmentation system (Meta’s SAM2 + Detectron2) that detects and geolocates electrical hardware on high-voltage lines from drone imagery — trained on a synthetic dataset with auto-generated masks, at Itaipu Parquetec.

SAM2 · Detectron2 · PyTorch

Overview

  • Researched and selected the model stack (Meta’s SAM2 + Detectron2) for an automated drone-based system that detects and geolocates electrical components on high-voltage transmission lines.
  • Engineered a synthetic data-generation pipeline that composites component instances with auto-generated segmentation masks, producing a 50K-image dataset (40K train / 10K test) — eliminating manual per-pixel annotation at scale.
  • Fine-tuned an 18-class Detectron2 instance-segmentation model on the synthetic set, reaching 70.1% box mAP (84.1% AP50) and 64.5% mask mAP on a 10K held-out test set.
  • Built an interactive SAM2-based annotation tool for images and video to bootstrap the initial labelling workflow.
  • Designed and prototyped the georeferencing engine: from DJI drone GPS + orientation metadata it localizes each detected component and resolves its transmission line and tower-to-tower span (5–7 conductors per span). Production frontend/backend built by the engineering team.
