Automated crystalline phase identification from XRD patterns

A single neural network that reads a raw X-ray diffraction pattern and identifies the material in one shot — its compound, crystal system, and unit-cell geometry — trained entirely on synthetic data.

Year
2025
Type
Undergraduate thesis
Role
Solo — data, model & app
Stack
TensorFlow · PyMatGen · Streamlit
Try the Streamlit app Source on GitHub

Overview

  • Built a multi-task 1D CNN that predicts chemical compound, crystal system and unit-cell parameters from a single X-ray diffraction pattern — reaching 89% compound accuracy (18 classes) and 98% crystal-system accuracy (6 classes) on 94 held-out, leakage-free test samples.
  • Engineered a fully synthetic training dataset to overcome scarce labelled data: simulated diffractograms from CIF crystallographic files with PyMatGen (Bragg’s law + structure factors), scaling 317 base patterns to ~2,000 via a domain-specific augmentation pipeline — angular shift, peak broadening, baseline drift and Gaussian noise.
  • Diagnosed and removed mislabelled samples (Fe₂O₃ tagged as cubic instead of its true trigonal phase) that were corrupting class boundaries and depressing accuracy — a manual label-noise audit that materially improved results.
  • Unified classification and regression heads with per-task masked loss weighting (cell lengths ~0.38 Å MAE, monoclinic β ~2.0°), and shipped an interactive Streamlit app with real-time, per-task confidence scores.
